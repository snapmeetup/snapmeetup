# SnapMeetUp

Prototype for an adults-only (18+) social username discovery website.

## Current prototype
- Responsive dark/pink UI
- Search and gender filters
- Free Snapchat profile links
- Premium social options shown as locked
- Profile submission demo stored locally in the browser
- 18+ confirmation on submission

## Important
This is the front-end prototype only. It does **not** yet include a real database, authentication, admin approval, premium activation, crypto payment verification, image uploads, or production moderation/age-assurance systems.

Before public launch, add server-side security, moderation/reporting, privacy/terms, age-assurance appropriate to applicable jurisdictions, and real payment verification.
